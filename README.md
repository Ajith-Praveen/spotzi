The working responsive web application is in [`claimshield/`](claimshield/README.md). Start it with `cd claimshield && python3 server.py` and open http://localhost:8000. It is installable as a PWA and keeps workflow data server-authoritative.

Design blueprint: [`idea/`](idea/README.md), including Precedent Intelligence for faster human review. `src/` holds an earlier front-end-only mock-up.
